# Approach
- Load Data and Initial Inspection (Check shape, data types, missing values, summary statistics).
- Data Cleaning and Feature Screening (Handle missing values, remove duplicates, leakage variables, irrelevant features).
- Exploratory Data Analysis (Analyze distributions, class balance, summary statistics).
- Feature Engineering (Scaling, normalization, ...).
- Building and training model (Split data; choose appropriate model: Linear Models, Tree-Based Models, Boosting, Neural
Networks; Model Fitting).
- Evaluation and Cross-Validation (Use metrics: Accuracy, Precision, Recall, F1, AUC, RMSE).
- Model Interpretation (Feature importance, SHAP values, coefficient analysis).
