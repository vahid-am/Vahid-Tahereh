## Approach
- Load data and initial inspection (Check shape, data types, missing values, summary statistics)
- Data Cleaning and preprocessing (handleing missing values, remove duplicates, leakage variables, irrelevant features, ...)
- Exploratory data analysis (Analyze distributions, class balance, summary statistics)
- Feature Engineering (Scaling, normalization, ...)
- Building and training model (data split, appropriate model selection: linear models, tree-based models, boosting, neural
networks, model Fitting)
- Evaluation and cross-validation (Accuracy, Precision, Recall, F1, AUC, RMSE, Cross-Validation)
